📸 How to Screenshot for Substack

  1. For Publication Logo (square): Screenshot ONLY the white box below (not the label). Make sure you capture the entire white box edge-to-edge.
  2. For Publication Wordmark (wide): Screenshot ONLY the second white box. Capture it edge-to-edge.
  3. Tip: Use a screenshot tool that lets you select the exact area (like Snipping Tool on Windows, or Shift+Cmd+4 on Mac).
  4. Crop tightly: Make sure there's no gray background in your screenshot - only the white box with the text.
