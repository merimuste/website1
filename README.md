# Personal Website Landing Page

A beautiful, elegant personal website with a classy, feminine aesthetic.

## Features

- **Elegant Typography**: Uses Cormorant Garamond (similar to Anastasia) for headings and Montserrat for body text
- **Visual Focus**: Large, beautiful imagery with minimal text
- **Link Tree Section**: Clean, organized links to your projects and social media
- **Responsive Design**: Looks beautiful on all devices
- **Soft Color Palette**: Cream, blush, and soft gray tones for a sophisticated feel

## Customization

### Update Your Name
In `index.html`, replace "Your Name" on line 18:
```html
<h1 class="name">Your Name</h1>
```

### Update Your Tagline
In `index.html`, replace the tagline on line 19:
```html
<p class="tagline">Creating moments of beauty</p>
```

### Change Images
Replace the Unsplash image URLs in `index.html` with your own images:
- Line 25: First hero image
- Line 40: Second landscape image

### Update Links
In `index.html`, update the link tree section (lines 49-64) with your actual URLs:
```html
<a href="your-link-here" class="link-item">
    <span class="link-text">Link Name</span>
</a>
```

### Customize Colors
In `style.css`, modify the color variables (lines 7-12):
```css
:root {
    --cream: #F9F6F1;
    --blush: #E8D5C4;
    --soft-gray: #8B8680;
    --charcoal: #3D3935;
    --white: #FFFFFF;
}
```

## Usage

Simply open `index.html` in your web browser to view your website locally, or deploy to any web hosting service.

## Design Philosophy

This website embraces:
- **Quiet elegance** over loud statements
- **Visual storytelling** through imagery
- **Thoughtful spacing** and typography
- **Feminine sophistication** without being overly minimalistic or childish
